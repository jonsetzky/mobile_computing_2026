# HW2's description

My implementation in the previous exercise by coincidence nearly completely completed this exercise's task by having two separate screens: bare image and details screen. Supporting back button was simple to add by adding a `BackHandler` button conditionally when the details screen is visible. The most difficult part of switching between thw views was implementing a visually acceptable animation.
